C++ — Вынесение класса в отдельный файл

Зачем разделять класс на файлы?

В реальных проектах на C++ каждый класс обычно выносят из main.cpp в пару отдельных файлов: заголовочный файл и файл реализации. Это делает код структурированным, ускоряет перекомпиляцию и позволяет легко переиспользовать классы в других программах.

Файл Расширение Что содержит
Заголовочный файл .h (или .hpp) Объявление класса: его имя, поля и прототипы (сигнатуры) методов без их реализации.
Файл реализации .cpp Определение (код) всех методов класса с указанием принадлежности классу через ::.
Главный файл main.cpp Подключает заголовочный файл и создает объекты класса для работы программы.

1. Заголовочный файл (Student.h)

В файле Student.h описывается структура класса. Вместо тела методов ставятся точки с запятой ;.

Чтобы избежать ошибки повторного включения файла при компиляции, используется директива #pragma once (или классические Include Guards: #ifndef / #define / #endif).

#pragma once // Защита от повторного подключения файла

#include <string>

// В заголовочных файлах не принято писать using namespace std;
// Поэтому используем полное имя std::string

class Student {
private:
    double gpa;

public:
    std::string name;
    int age;

    // Только объявления (прототипы) методов
    void setGpa(double value);
    void printInfo();
};
Совет: Никогда не пишите using namespace std; в .h-файлах — это загрязняет глобальное пространство имен во всех файлах, куда будет подключен этот заголовок.

2. Файл реализации (Student.cpp)

В файле Student.cpp мы подключаем свой заголовочный файл через двойные кавычки #include "Student.h" и пишем код методов.

Чтобы компилятор понял, что функция относится именно к классу Student, перед именем метода ставится оператор разрешения области видимости Student::.

#include "Student.h" // Подключаем объявление нашего класса
#include <iostream>

using namespace std;

// Реализация метода setGpa класса Student
void Student::setGpa(double value) {
    if (value >= 0.0 && value <= 5.0) {
        gpa = value;
    }
}

// Реализация метода printInfo класса Student
void Student::printInfo() {
    cout << "Имя: " << name << ", Возраст: " << age << ", Средний балл: " << gpa << endl;
}
Обратите внимание: Тип возвращаемого значения (например, void) пишется до имени класса: void Student::setGpa(double value).

3. Использование в основной программе (main.cpp)

В main.cpp достаточно подключить только заголовочный файл "Student.h". Подключать "Student.cpp" через #include нельзя — компоновщик (linker) сам свяжет скомпилированные .cpp-файлы проекта.

#include "Student.h"

int main() {
    Student s1;

    s1.name = "Алексей";
    s1.age = 20;

    s1.setGpa(4.7);
    s1.printInfo(); // Выведет: Имя: Алексей, Возраст: 20, Средний балл: 4.7

    return 0;
}

Чек-лист при вынесении класса

  • Системные библиотеки подключаются в угловых скобках: #include <iostream>.
  • Свои заголовочные файлы подключаются в кавычках: #include "Student.h".
  • В .h-файле всегда добавляется #pragma once в самой первой строке.
  • В .cpp-файле у каждого метода указывается префикс ИмяКласса::, а у полей внутри методов префикс не нужен.
  • Не подключайте .cpp через #include — добавляйте все .cpp-файлы в сборку проекта (CMake, Visual Studio, g++ main.cpp Student.cpp).
