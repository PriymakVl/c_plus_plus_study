C++ — Сеттеры (методы установки значений)

Что такое сеттер

Сеттер (от англ. set — устанавливать) — это публичный метод класса, который позволяет безопасно изменять значение приватного (private) или защищённого (protected) поля.

  • Валидация данных — перед записью значения в поле сеттер может проверить его корректность (например, не допускать отрицательный возраст или пустое имя), защищая объект от некорректного состояния.
  • Именование — по соглашению имена сеттеров начинаются с префикса set, за которым следует имя поля с заглавной буквы (например, setGpa(), setName()).
  • Возвращаемый тип — обычно сеттеры имеют тип void (ничего не возвращают), но иногда возвращают bool (успешна ли запись) или ссылку на текущий объект *this для цепочки вызовов.

1. Создание и использование сеттеров

Добавим сеттеры с проверкой входных данных в класс Student, чтобы исключить запись недопустимых значений.

#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int age;
    double gpa;

public:
    // Сеттеры с проверкой корректности данных
    void setName(const string& newName) {
        if (!newName.empty()) {
            name = newName;
        }
    }

    void setAge(int newAge) {
        if (newAge >= 16 && newAge <= 100) {
            age = newAge;
        }
    }

    void setGpa(double value) {
        if (value >= 0.0 && value <= 5.0) {
            gpa = value;
        }
    }

    // Геттеры для чтения значений
    string getName() const { return name; }
    int getAge() const { return age; }
    double getGpa() const { return gpa; }
};

int main() {
    Student s1;

    // Установка значений через сеттеры
    s1.setName("Алексей");
    s1.setAge(20);
    s1.setGpa(4.7);

    // Попытка передать некорректное значение будет проигнорирована
    s1.setGpa(10.5);

    cout << "Имя: " << s1.getName() << endl;
    cout << "Возраст: " << s1.getAge() << endl;
    cout << "Средний балл: " << s1.getGpa() << endl; // Выведет 4.7

    return 0;
}
Важно: В отличие от геттеров, сеттеры изменяют состояние объекта, поэтому модификатор const после списка параметров у них не ставится.

2. Передача параметров в сеттер

Способ передачи аргумента в сеттер зависит от типа данных обновляемого поля.

Способ передачи Синтаксис Когда применять
По значению void setAge(int newAge) Для примитивных типов (int, double, bool, char), которые быстро копируются.
По константной ссылке void setName(const string& newName) Для крупных объектов (std::string, std::vector и др.), чтобы избежать лишнего копирования при передаче в метод.
Совет: Если имя параметра сеттера совпадает с именем поля класса (например, void setAge(int age)), используйте указатель this->age = age;, чтобы избежать конфликта имён.

3. Цепочка вызовов (Method Chaining)

Если сеттер возвращает ссылку на текущий объект (*this), методы можно вызывать последовательно в одну строку.

class Box {
private:
    double width = 0;
    double height = 0;

public:
    Box& setWidth(double w) {
        if (w > 0) width = w;
        return *this; // Возвращаем ссылку на текущий объект
    }

    Box& setHeight(double h) {
        if (h > 0) height = h;
        return *this;
    }
};

int main() {
    Box b;
    // Цепочка вызовов сеттеров
    b.setWidth(10.5).setHeight(20.0);

    return 0;
}
