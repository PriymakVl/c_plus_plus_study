C++ — Конструкторы в классах

Что такое конструктор

Конструктор — это специальный метод класса, который автоматически вызывается при создании объекта. Его главная задача — инициализация полей объекта начальными значениями и выделение необходимых ресурсов.

  • Имя конструктора всегда полностью совпадает с именем класса.
  • Тип возвращаемого значения отсутствует (не пишется даже void).
  • Модификатор доступа обычно public, чтобы объекты можно было создавать извне класса.
  • Перегрузка поддерживается — в одном классе может быть несколько конструкторов с разными наборами параметров.

1. Конструктор по умолчанию (без параметров)

Вызывается автоматически, когда объект создаётся без передачи аргументов. Если в классе не объявлен ни один конструктор, компилятор создаёт пустой конструктор по умолчанию самостоятельно.

#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int age;
    double gpa;

public:
    // Конструктор по умолчанию
    Student() {
        name = "Неизвестно";
        age = 18;
        gpa = 0.0;
        cout << "Вызван конструктор по умолчанию" << endl;
    }

    void printInfo() {
        cout << "Имя: " << name << ", Возраст: " << age << ", Средний балл: " << gpa << endl;
    }
};

int main() {
    Student s1; // Автоматически вызывается Student()
    s1.printInfo(); // Выведет: Имя: Неизвестно, Возраст: 18, Средний балл: 0
    return 0;
}

2. Параметризованный конструктор и список инициализации

Позволяет передать начальные данные сразу при создании объекта. Для инициализации полей рекомендуется использовать список инициализации (через двоеточие : после заголовка конструктора) — это работает быстрее и обязательно для константных (const) полей и ссылок.

#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int age;
    double gpa;

public:
    // Параметризованный конструктор со списком инициализации
    Student(string studentName, int studentAge, double studentGpa)
        : name(studentName), age(studentAge), gpa(studentGpa) {
        // Тело конструктора может оставаться пустым или содержать проверки
        if (gpa < 0.0 || gpa > 5.0) {
            gpa = 0.0;
        }
    }

    void printInfo() {
        cout << "Имя: " << name << ", Возраст: " << age << ", Средний балл: " << gpa << endl;
    }
};

int main() {
    // Создание объектов с передачей аргументов в конструктор
    Student s1("Алексей", 20, 4.7);
    Student s2{"Мария", 19, 4.9}; // Унифицированная инициализация (C++11)

    s1.printInfo();
    s2.printInfo();

    return 0;
}
Важно: Если вы объявили свой конструктор с параметрами, компилятор перестаёт автоматически создавать конструктор по умолчанию. Чтобы сохранить возможность создавать объекты без параметров (Student s;), нужно объявить конструктор по умолчанию явно или написать Student() = default;.

3. Конструктор копирования и делегирование

В C++ также часто используются дополнительные виды конструкторов для удобства и безопасной работы с памятью:

  • Конструктор копирования (ClassName(const ClassName& other)) — создаёт новый объект как точную копию уже существующего.
  • Делегирующий конструктор (C++11) — позволяет одному конструктору вызывать другой конструктор этого же класса через список инициализации, избавляя от дублирования кода.
class Rectangle {
private:
    double width;
    double height;

public:
    // Основной параметризованный конструктор
    Rectangle(double w, double h) : width(w), height(h) {}

    // Делегирующий конструктор (квадрат — частный случай прямоугольника)
    Rectangle(double side) : Rectangle(side, side) {}

    // Конструктор копирования
    Rectangle(const Rectangle& other) : width(other.width), height(other.height) {
        cout << "Объект скопирован" << endl;
    }

    double area() {
        return width * height;
    }
};

int main() {
    Rectangle r1(4.0, 5.0); // Основной конструктор
    Rectangle r2(3.0);      // Делегирующий конструктор (3.0 x 3.0)
    Rectangle r3 = r1;      // Конструктор копирования

    return 0;
}

Сравнение видов конструкторов

Вид конструктора Синтаксис объявления Когда вызывается
По умолчанию Student() При создании объекта без аргументов: Student s;
Параметризованный Student(string n, int a) При передаче аргументов: Student s("Иван", 19);
Копирования Student(const Student& other) При инициализации копией: Student s2 = s1; или передаче по значению
Делегирующий Student() : Student("Нет имени", 18) Перенаправляет инициализацию другому конструктору того же класса
