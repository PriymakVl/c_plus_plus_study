C++ — Несколько объектов в C++

Несколько объектов одного класса

Один класс является шаблоном, на основе которого можно создать сколько угодно объектов (экземпляров). У каждого объекта выделяется своя область памяти под поля: изменение значения поля одного объекта никак не влияет на поля других объектов.

Важно: Каждый созданный объект независим и хранит собственное состояние (свои значения полей), даже если все объекты созданы по одному и тому же классу.

1. Объявление класса

Опишем класс User с публичным полем age, задав ему начальное значение по умолчанию:

#include <iostream>

class User {
public:
    int age = 0;
};

2. Создание и использование нескольких объектов

Создадим два отдельных объекта user1 и user2, запишем в их поля age разные значения и выведем результат на экран:

#include <iostream>

class User {
public:
    int age = 0;
};

int main() {
    // Создание двух независимых объектов
    User user1;
    User user2;

    // Установка разных значений для каждого объекта
    user1.age = 20;
    user2.age = 30;

    // Вывод значений полей
    std::cout << user1.age << "\n"; // выведет 20
    std::cout << user2.age << "\n"; // выведет 30

    return 0;
}
