C++ — Структуры и классы

Что такое структура и класс

В C++ структура (struct) и класс (class) — это пользовательские типы данных, которые позволяют объединить переменные разных типов (поля) и функции для работы с ними (методы) в единую сущность.

  • Поля (атрибуты) — переменные внутри структуры или класса, описывающие состояние объекта.
  • Методы — функции внутри структуры или класса, определяющие поведение объекта.
  • Объект (экземпляр) — конкретная переменная, созданная на основе структуры или класса.

1. Структура (struct)

Исторически структуры пришли из языка C как способ группировки данных. В C++ структуры могут содержать не только поля, но и методы, конструкторы и деструкторы. Главная особенность struct — все члены по умолчанию открыты (public).

#include <iostream>
#include <string>
using namespace std;

// Объявление структуры
struct Point {
    // По умолчанию модификатор доступа — public
    double x;
    double y;

    // Метод внутри структуры
    void print() {
        cout << "Точка (" << x << "; " << y << ")" << endl;
    }
};

int main() {
    Point p1 = {3.5, 7.2}; // Агрегатная инициализация
    p1.x = 5.0;            // Прямой доступ к полю разрешен
    p1.print();            // Выведет: Точка (5; 7.2)

    return 0;
}

2. Класс (class)

Класс — основа объектно-ориентированного программирования (ООП) в C++. Главная особенность class — все члены по умолчанию закрыты (private), что обеспечивает инкапсуляцию и защиту данных от некорректного изменения извне.

#include <iostream>
#include <string>
using namespace std;

// Объявление класса
class BankAccount {
private:
    // Приватное поле (по умолчанию в class, доступно только внутри класса)
    double balance;

public:
    // Публичное поле
    string owner;

    // Метод для безопасного пополнения счета
    void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    // Метод для получения значения закрытого поля (геттер)
    double getBalance() {
        return balance;
    }
};

int main() {
    BankAccount acc;
    acc.owner = "Иван";
    // acc.balance = 1000; // Ошибка компиляции: поле balance закрыто (private)
    
    acc.deposit(1500.0);
    cout << acc.owner << ": " << acc.getBalance() << " руб." << endl;

    return 0;
}
Важно: В конце определения как структуры, так и класса после закрывающей фигурной скобки } обязательно ставится точка с запятой ;.

3. Сравнение struct и class

С технической точки зрения в C++ между struct и class почти нет разницы: оба поддерживают наследование, полиморфизм, шаблоны, конструкторы и модификаторы доступа. Отличия заключаются лишь в правах доступа по умолчанию и соглашениях о стиле кода:

Критерий Структура (struct) Класс (class)
Доступ к полям и методам по умолчанию public (открытый) private (закрытый)
Наследование по умолчанию public private
Типичное применение Простые наборы данных (POD-типы), координаты, настройки, где нет сложной логики защиты. Полноценные объекты со сложным поведением, инкапсуляцией и проверкой корректности состояния.
