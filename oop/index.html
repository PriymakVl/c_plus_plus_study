1 Структуры и классы Пользовательские типы данных struct и class, модификаторы доступа по умолчанию (public и private) и их сравнение
2 Классы, поля и методы Понятие класса и объекта, объявление полей и методов, модификаторы public/private и обращение через оператор .
3 Несколько объектов класса Создание нескольких независимых экземпляров одного класса с выделением собственной области памяти под поля каждого объекта

5 Конструкторы в классах Конструкторы по умолчанию, параметризованные со списком инициализации, конструкторы копирования и делегирующие конструкторы
6 Геттеры (методы доступа) Публичные const-методы для чтения приватных полей, возврат по значению и по константной ссылке, вычисляемые геттеры
7 Сеттеры (методы установки значений) Методы для безопасного изменения приватных полей с валидацией данных, способы передачи параметров и цепочка вызовов (*this)
8 Константные методы (const) Методы с модификатором const, гарантирующие неизменность объекта, ключевое слово mutable и перегрузка по const
