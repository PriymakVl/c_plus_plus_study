C++ — Геттеры (методы доступа)

Что такое геттер

Геттер (от англ. get — получать) — это публичный метод класса, который возвращает значение приватного (private) или защищённого (protected) поля.

  • Инкапсуляция — скрытие внутренних данных класса от прямого изменения извне, предоставляя контролируемый доступ только для чтения.
  • Именование — по соглашению имена геттеров начинаются с префикса get, за которым следует имя поля с заглавной буквы (например, getGpa(), getName()), или используются префиксы is / has для логических полей (isActive()).
  • Константность (const) — геттеры не должны изменять состояние объекта, поэтому в их сигнатуре обязательно ставится модификатор const.

1. Создание и использование геттеров

Добавим геттеры в класс Student, чтобы безопасно получать значения закрытых полей.

#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    int age;
    double gpa;

public:
    // Сеттеры для записи значений
    void setName(const string& newName) {
        if (!newName.empty()) {
            name = newName;
        }
    }

    void setAge(int newAge) {
        if (newAge > 0) {
            age = newAge;
        }
    }

    void setGpa(double value) {
        if (value >= 0.0 && value <= 5.0) {
            gpa = value;
        }
    }

    // Геттеры для получения значений (помечены как const)
    string getName() const {
        return name;
    }

    int getAge() const {
        return age;
    }

    double getGpa() const {
        return gpa;
    }
};

int main() {
    Student s1;
    s1.setName("Алексей");
    s1.setAge(20);
    s1.setGpa(4.7);

    // Получение данных через геттеры
    cout << "Имя: " << s1.getName() << endl;
    cout << "Возраст: " << s1.getAge() << endl;
    cout << "Средний балл: " << s1.getGpa() << endl;

    return 0;
}
Важно: Ключевое слово const после списка параметров метода гарантирует компилятору, что метод не изменяет поля объекта. Это позволяет вызывать геттеры даже у константных объектов (const Student s2;).

2. Возврат по значению и по константной ссылке

Выбор способа возврата данных из геттера зависит от типа поля и его размера в памяти.

Способ возврата Синтаксис Когда применять
По значению int getAge() const Для примитивных типов (int, double, bool, char), копирование которых дёшево.
По константной ссылке const string& getName() const Для тяжёлых объектов (std::string, std::vector и др.), чтобы избежать лишнего копирования в памяти и запретить изменение оригинала.
Совет: Никогда не возвращайте из геттера неконстантную ссылку (string& getName()), так как это нарушит инкапсуляцию и позволит изменить приватное поле напрямую в обход сеттера.

3. Вычисляемые геттеры

Геттер не обязан напрямую возвращать существующее поле класса — он может вычислять результат на основе других данных.

class Rectangle {
private:
    double width;
    double height;

public:
    Rectangle(double w, double h) : width(w), height(h) {}

    double getWidth() const { return width; }
    double getHeight() const { return height; }

    // Вычисляемый геттер (поля area в классе нет)
    double getArea() const {
        return width * height;
    }
};
