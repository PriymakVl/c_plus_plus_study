C++ — Константные методы (const)

Что такое константный метод

Константный метод — это метод класса, который гарантирует, что при его вызове состояние объекта (значения его полей) не будет изменено.

  • Синтаксис: ключевое слово const указывается после списка параметров метода (и в объявлении, и в определении).
  • Безопасность: компилятор запрещает изменять поля объекта внутри такого метода и вызывать из него другие неконстантные методы.
  • Работа с const-объектами: для константных объектов (или ссылок/указателей на них) можно вызывать только константные методы.

1. Синтаксис и пример использования

Обычно константными делают геттеры и методы вывода информации, так как они только читают данные объекта, не модифицируя их.

#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
    double gpa;

public:
    Student(string n, double g) : name(n), gpa(g) {}

    // Обычный (неконстантный) метод — может изменять поля
    void setGpa(double value) {
        if (value >= 0.0 && value <= 5.0) {
            gpa = value;
        }
    }

    // Константный метод (геттер) — только чтение
    double getGpa() const {
        return gpa;
    }

    // Константный метод вывода информации
    void printInfo() const {
        // gpa = 5.0; // ОШИБКА КОМПИЛЯЦИИ: нельзя менять поля в const-методе
        cout << "Студент: " << name << ", Средний балл: " << gpa << endl;
    }
};
Важно: Если метод разделён на объявление в классе и определение за его пределами, ключевое слово const необходимо писать в обоих местах: void Student::printInfo() const { ... }.

2. Вызов для константных и обычных объектов

Константные методы универсальны: их можно вызывать как для обычных, так и для константных объектов (например, при передаче объекта в функцию по константной ссылке const Student&).

void showStudent(const Student& s) {
    // s — константная ссылка, доступны только const-методы
    s.printInfo(); // ОК
    // s.setGpa(4.9); // ОШИБКА: setGpa() не является константным
}

int main() {
    Student s1("Алексей", 4.7);
    s1.setGpa(4.8);   // ОК: объект неконстантный
    s1.printInfo();   // ОК: const-метод можно вызвать для обычного объекта

    const Student s2("Мария", 5.0);
    s2.printInfo();   // ОК: printInfo() помечен как const
    // s2.setGpa(4.5); // ОШИБКА: нельзя вызывать неконстантный метод для const-объекта

    showStudent(s1);

    return 0;
}

3. Ключевое слово mutable и перегрузка

В редких случаях требуется изменять служебное поле (например, счётчик обращений или кэш) внутри константного метода, не нарушая логическую константность объекта.

  • mutable — модификатор поля класса, разрешающий его изменение даже внутри const-методов.
  • Перегрузка по const — в классе могут существовать два метода с одинаковым именем и параметрами, один из которых const, а другой — нет. Компилятор выберет нужный в зависимости от константности объекта.
class Logger {
private:
    mutable int readCount = 0; // Можно менять в const-методах
    string message;

public:
    Logger(string msg) : message(msg) {}

    string getMessage() const {
        readCount++; // Разрешено благодаря mutable
        return message;
    }
};
Совет: Всегда помечайте как const все методы, которые не изменяют состояние объекта. Это защищает код от случайных ошибок и делает классы удобными для работы с константными ссылками.
