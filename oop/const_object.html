C++ — Константные объекты и методы

Что такое константный объект

Константный объект — это экземпляр класса, объявленный с ключевым словом const. После создания и инициализации (с помощью конструктора) состояние такого объекта нельзя изменить на протяжении всего времени его жизни.

  • Запрет изменения полей: любая попытка присвоить новое значение полям константного объекта приведёт к ошибке компиляции.
  • Вызов только константных методов: для константного объекта можно вызывать исключительно те методы, которые помечены как const (гарантируют, что объект не будет изменён).
  • Обязательная инициализация: константный объект должен быть инициализирован при создании (через конструктор или список инициализации).

1. Константные методы (const-методы)

Чтобы метод можно было вызывать у константного объекта, после списка параметров в его объявлении и определении указывается модификатор const. Такой метод не имеет права изменять поля класса и вызывать неконстантные методы.

#include <iostream>
#include <string>
using namespace std;

class Book {
private:
    string title;
    int pages;

public:
    // Конструктор для инициализации полей
    Book(string t, int p) : title(t), pages(p) {}

    // Обычный (неконстантный) метод — изменяет состояние объекта
    void setPages(int p) {
        if (p > 0) {
            pages = p;
        }
    }

    // Константный метод — только читает данные, не меняя объект
    void printInfo() const {
        // pages = 100; // ОШИБКА: внутри const-метода нельзя менять поля!
        cout << "Книга: «" << title << "», страниц: " << pages << endl;
    }

    int getPages() const {
        return pages;
    }
};
Хорошая практика: Все методы, которые не изменяют состояние объекта (например, геттеры get...() или методы вывода информации), рекомендуется всегда объявлять как const.

2. Создание и использование константного объекта

Константный объект создаётся так же, как и обычная константная переменная — с указанием ключевого слова const перед типом класса или после него.

int main() {
    // Обычный (изменяемый) объект
    Book b1("Война и мир", 1200);
    b1.setPages(1300); // Разрешено
    b1.printInfo();    // Разрешено (обычный объект может вызывать const-методы)

    // Константный объект
    const Book b2("Мастер и Маргарита", 480);
    b2.printInfo();    // Разрешено: метод printInfo() помечен как const
    cout << "Страниц: " << b2.getPages() << endl; // Разрешено

    // b2.setPages(500); // ОШИБКА КОМПИЛЯЦИИ: нельзя вызвать неконстантный метод!

    return 0;
}

3. Ключевое слово mutable и перегрузка по const

В C++ существуют два важных механизма, тесно связанных с константными объектами:

  • mutable — модификатор поля класса, который разрешает изменять это конкретное поле даже внутри const-методов и у константных объектов (например, для счётчиков вызовов или кэширования).
  • Перегрузка методов по const — в классе могут существовать два метода с одинаковым именем и параметрами, один из которых const, а другой — нет. Для константного объекта компилятор выберет const-версию.
class Counter {
private:
    int value;
    mutable int readCount = 0; // Можно менять даже в const-объекте

public:
    Counter(int v) : value(v) {}

    int getValue() const {
        readCount++; // Разрешено благодаря mutable
        return value;
    }

    // Перегрузка по const
    void show() {
        cout << "Обычный объект: " << value << endl;
    }

    void show() const {
        cout << "Константный объект: " << value << endl;
    }
};
Совет: Передача объектов в функции по константной ссылке (void func(const Book& b)) — стандарт в C++. Это позволяет избежать лишнего копирования объекта в памяти и одновременно защищает его от случайного изменения внутри функции.

4. Сравнение обычного и константного объектов

Характеристика Обычный объект (Class obj) Константный объект (const Class obj)
Изменение публичных полей Разрешено Запрещено
Вызов обычных методов Разрешён Запрещён (ошибка компиляции)
Вызов const-методов Разрешён Разрешён
Изменение mutable-полей Разрешено Разрешено (внутри const-методов)
