C++ — Обращение через this

Что такое this

Внутри методов класса доступна специальная переменная (указатель) this, которая указывает на текущий объект класса, для которого был вызван метод.

class User {
public:
    void show() {
        // this — указатель на текущий объект
    }
};
Важно: Поскольку this является указателем на объект, обращение к полям и методам через него выполняется с помощью оператора стрелки -> (например, this->name), а не через точку.

1. Доступ к полям объекта через this

Чтобы обратиться к полю объекта внутри метода, имя поля записывается после стрелки: this->name. Рассмотрим класс User с полем name и методом show(), который возвращает значение этого поля:

#include <string>

class User {
public:
    std::string name;

    std::string show() {
        return this->name;
    }
};

2. Использование в программе

Создадим объект класса User, присвоим значение полю name и вызовем метод show() для вывода результата на экран:

#include <iostream>
#include <string>

class User {
public:
    std::string name;

    std::string show() {
        return this->name;
    }
};

int main() {
    // Создание объекта класса
    User user;

    // Запись значения в поле
    user.name = "john";

    // Вызов метода для вывода значения поля
    std::cout << user.show() << "\n"; // выведет john

    return 0;
}
