C++ — Классы, поля и методы

Что такое класс и объект

Класс (class) — это пользовательский тип данных (шаблон), который объединяет данные и функции для работы с ними. Объект — это конкретный экземпляр класса.

  • Поля (атрибуты) — переменные внутри класса, описывающие состояние объекта.
  • Методы — функции внутри класса, определяющие поведение объекта.
  • Модификаторы доступа — public (доступно отовсюду) и private (доступно только внутри класса, используется по умолчанию).

1. Создание класса

Объявление класса описывает его структуру (поля и методы) и обязательно завершается точкой с запятой ;.

#include <iostream>
#include <string>
using namespace std;

// Объявление класса
class Student {
private:
    double gpa; // Приватное поле (доступно только внутри класса)

public:
    // Публичные поля
    string name;
    int age;

    // Метод для установки приватного поля
    void setGpa(double value) {
        if (value >= 0.0 && value <= 5.0) {
            gpa = value;
        }
    }

    // Метод для вывода информации
    void printInfo() {
        cout << "Имя: " << name << ", Возраст: " << age << ", Средний балл: " << gpa << endl;
    }
};
Важно: В конце определения класса после закрывающей фигурной скобки } обязательно ставится точка с запятой ;.

2. Использование класса

Чтобы использовать класс, нужно создать его экземпляр (объект). Доступ к открытым полям и методам объекта осуществляется через оператор точки (.).

int main() {
    // Создание объекта (экземпляра класса)
    Student s1;

    // Обращение к публичным полям
    s1.name = "Алексей";
    s1.age = 20;

    // Вызов методов объекта
    s1.setGpa(4.7);
    s1.printInfo(); // Выведет: Имя: Алексей, Возраст: 20, Средний балл: 4.7

    return 0;
}
