1. Арифметичні оператори

Арифметичні оператори виконують математичні обчислення над значеннями (операндами).

ОператорНазваПрикладРезультат (якщо a = 10, b = 3)
+Додаванняa + b13
-Відніманняa - b7
*Множенняa * b30
/Діленняa / b3 (цілочисельне ділення)
%Остача від діленняa % b1 (10 = 3 * 3 + 1)
Зверніть увагу! Оператор остачі від ділення (%) працює тільки з цілими числами (int, short, long). Якщо використати його з double, виникне помилка компіляції.

2. Оператори присвоєння та комбіновані оператори

Базовий оператор присвоєння — це =. Він копіює значення з правої частини у змінну ліворуч.

Для скорочення запису стандартних операцій використовуються комбіновані оператори:

Скорочений записПовний еквівалентОпис
x += 5;x = x + 5;Збільшити x на 5
x -= 3;x = x - 3;Зменшити x на 3
x *= 2;x = x * 2;Помножити x на 2
x /= 4;x = x / 4;Поділити x на 4
x %= 10;x = x % 10;Отримати остачу від ділення x на 10
#include <iostream>
using namespace std;

int main() {
    int score = 100;
    score += 50;  // score тепер 150
    score *= 2;   // score тепер 300
    cout << "Score: " << score << endl;
    return 0;
}

3. Інкремент (++) та Декремент (--)

Оператори інкременту (++) та декременту (--) збільшують або зменшують значення змінної на 1.

Префіксна форма (++x)

Спочатку змінює значення змінної, а потім використовує нове значення у виразі.

int a = 5;
int b = ++a; // a = 6, b = 6

Постфіксна форма (x++)

Спочатку використовує поточне значення у виразі, а потім змінює значення змінної.

int a = 5;
int b = a++; // b = 5, a = 6
Запам'ятай: Якщо операція виконується окремим рядком (наприклад, count++;), різниці між ++count та count++ немає.

4. Оператори порівняння (відношення)

Використовуються для порівняння двох значень. Результатом завжди є логічне значення: true (1) або false (0).

ОператорЗначенняПрикладРезультат (якщо x = 5)
==Рівноx == 5true
!=Не дорівнюєx != 5false
>Більшеx > 3true
<Меншеx < 10true
>=Більше або дорівнюєx >= 5true
<=Менше або дорівнюєx <= 4false
Типова помилка початківців: Плутанина між = (присвоєння) та == (перевірка на рівність). Запис if (a = 5) присвоїть змінній значення 5 і завжди поверне true!

5. Логічні оператори

Використовуються для поєднання декількох умов.

ОператорНазваОписПриклад
&&Логічне І (AND)Повертає true, тільки якщо обидва операнди є true(age >= 18 && age <= 65)
||Логічне АБО (OR)Повертає true, якщо хоча б один з операндів є true(isWeekend || isHoliday)
!Логічне НЕ (NOT)Змінює значення на протилежне (інверсія)!(x > 5)
#include <iostream>
using namespace std;

int main() {
    int age = 20;
    bool hasLicense = true;

    if (age >= 18 && hasLicense) {
        cout << "You can drive a car!" << endl;
    }

    return 0;
}

7. Практика — пишемо самі

Завдання 1. Парне чи непарне. Ввести ціле число та перевірити, чи є воно парним (використати оператор %).
Код для вчителя
#include <iostream>
using namespace std;

int main() {
    int number;
    cout << "Enter a number: ";
    cin >> number;

    if (number % 2 == 0) {
        cout << number << " is even." << endl;
    } else {
        cout << number << " is odd." << endl;
    }

    return 0;
}
Завдання 2. Калькулятор остачі та ділення. Користувач вводить два числа. Програма виводить результат цілочисельного ділення та остачу.
Код для вчителя
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cout << "a = ";
    cin >> a;
    cout << "b = ";
    cin >> b;

    cout << "Quotient: " << a / b << endl;
    cout << "Remainder: " << a % b << endl;

    return 0;
}
Завдання 3. Перевірка діапазону. Ввести число і перевірити, чи належить воно відрізку від 10 до 50 включно.
Код для вчителя
#include <iostream>
using namespace std;

int main() {
    int x;
    cout << "Enter x: ";
    cin >> x;

    if (x >= 10 && x <= 50) {
        cout << "In range!" << endl;
    } else {
        cout << "Out of range!" << endl;
    }

    return 0;
}
Завдання 4. Розділення трьохзначного числа на цифри. Ввести тризначне число (наприклад, 357) і вивести суму його цифр.
Рішення
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter 3-digit number: ";
    cin >> n;

    int d1 = n / 100;       // Перша цифра (сотні)
    int d2 = (n / 10) % 10; // Друга цифра (десятки)
    int d3 = n % 10;        // Третя цифра (одиниці)

    int sum = d1 + d2 + d3;
    cout << "Sum of digits: " << sum << endl;

    return 0;
}

9. Підсумкова програма

Напишіть програму «Аналіз часу»: користувач вводить кількість секунд. Програма переводить їх у години, хвилини та залишок секунд за допомогою цілочисельного ділення та остачі від ділення.

Рішення для вчителя
#include <iostream>
using namespace std;

int main() {
    int totalSeconds;
    cout << "Enter total seconds: ";
    cin >> totalSeconds;

    int hours = totalSeconds / 3600;
    int minutes = (totalSeconds % 3600) / 60;
    int seconds = totalSeconds % 60;

    cout << hours << "h " << minutes << "m " << seconds << "s" << endl;

    return 0;
}

Що перевіряємо: оператори /, %, змінні, форматований вивід через cout.
