C++ — Двовимірні масиви

1. Що таке двовимірний масив

Двовимірний масив можна уявити як таблицю чи матрицю, яка складається з рядків та стовпчиків. Кожен елемент має два індекси: номер рядка та номер стовпчика.

Синтаксис оголошення:

тип_даних ім_я_масиву[кількість_рядків][кількість_стовпчиків];
Приклад Опис
int matrix[3][4]; Таблиця з 3 рядків та 4 стовпчиків (усього 12 елементів)
char board[8][8]; Шахівниця 8x8 з символів

2. Ініціалізація та доступ за індексами

При ініціалізації значення зазвичай групують у фігурні дужки за рядками:

#include <iostream>
using namespace std;

int main() {
    int matrix[2][3] = {
        {10, 20, 30}, // Рядок 0
        {40, 50, 60}  // Рядок 1
    };

    // Доступ до елемента у 2-му рядку (індекс 1) та 3-му стовпчику (індекс 2)
    cout << "Елемент: " << matrix[1][2] << endl; // 60

    matrix[0][0] = 99; // Зміна першого елемента першого рядка
    return 0;
}
Пам'ятай: Перший індекс завжди вказує на рядок, а другий — на стовпчик: arr[row][col].

3. Обхід двовимірного масиву (Вкладені цикли)

Для обробки всіх елементів двовимірного масиву використовують два вкладені цикли for: зовнішній — по рядках, внутрішній — по стовпчиках.

#include <iostream>
using namespace std;

int main() {
    const int ROWS = 3;
    const int COLS = 3;
    int grid[ROWS][COLS] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    // Вивід матриці у вигляді таблиці
    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLS; j++) {
            cout << grid[i][j] << "\t";
        }
        cout << endl; // Перехід на новий рядок після кожного рядка матриці
    }

    return 0;
}
