C++ — Базові масиви

1. Що таке масив та як його оголосити

Масив — це впорядкована сукупність елементів одного типу, які розташовані у пам'яті послідовно та мають спільне ім'я.

Синтаксис оголошення одномірного масиву:

тип_даних ім_я_масиву[розмір];
Приклад Опис
int numbers[5]; Масив з 5 цілих чисел
double temp[7]; Масив з 7 дробових чисел
char letters[10]; Масив з 10 символів
Важливо! Елементи масиву нумеруються з 0. Перший елемент має індекс 0, а останній у масиві з N елементів — індекс N - 1.

2. Ініціалізація масивів

Надати початкові значення елементам масиву можна одразу при оголошенні за допомогою фігурних дужок:

#include <iostream>
using namespace std;

int main() {
    // Повна ініціалізація
    int arr[4] = {10, 20, 30, 40}; 

    // Автоматичне визначення розміру (розмір буде 3)
    int autoArr[] = {5, 15, 25};

    // Часткова ініціалізація (решта елементів заповнюються нулями)
    int zeroArr[5] = {1, 2}; // {1, 2, 0, 0, 0}

    return 0;
}

3. Доступ до елементів та зміна значень

Звернення до конкретного елемента виконується за його індексом у квадратних дужках:

#include <iostream>
using namespace std;

int main() {
    int arr[4] = {10, 20, 30, 40};

    cout << "Перший елемент: " << arr[0] << endl; // 10
    
    arr[2] = 99; // Зміна третього елемента (індекс 2)
    cout << "Новий третій елемент: " << arr[2] << endl; // 99

    return 0;
}
Запам'ятай: Вихід за межі масиву (наприклад, звернення до arr[10] у масиві з 5 елементів) призводить до невизначеної поведінки (Undefined Behavior).
