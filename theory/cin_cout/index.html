C++ — Введення та виведення (cin і cout)

# Name Remark
1 Введення та виведення (cin і cout) Робота з об'єктом cout та оператором <<, перехід на новий рядок (endl проти "\n"), зчитування даних через cin >>
2 Зчитування рядків (getline) Особливість зчитування cin >> string до першого пробілу та використання функції getline(cin, variable) для зчитування повного рядка
3 Форматування дробових чисел (iomanip) Встановлення точної кількості знаків після коми за допомогою прапорців fixed та setprecision(n) з бібліотеки <iomanip>
