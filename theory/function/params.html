Передача за значенням та за посиланням (&)

За замовчуванням параметри передаються за значенням (створюється копія). Щоб функція могла змінити значення оригінальної змінної, використовують амперсанд & (передача за посиланням).

void swap(int &a, int &b) { // & дозволяє змінювати оригінали
    int temp = a;
    a = b;
    b = temp;
}
Тип передачі Синтаксис Опис Змінює оригінал?
За значенням (int a) Передається копія даних Ні
За посиланням (int &a) Передається адреса самої змінної Так
Константне посилання (const string &s) Передача без копіювання (швидко), але без права зміни Ні
