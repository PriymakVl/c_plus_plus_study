C++ — Параметры и аргументы функций

1. Параметры и аргументы: в чём разница

  • Параметры — переменные, указанные в круглых скобках при объявлении или определении функции.
  • Аргументы — реальные значения или переменные, которые передаются в функцию при её вызове.
  • Количество и типы аргументов при вызове должны соответствовать параметрам функции.
#include <iostream>
using namespace std;

// a и b — параметры функции
int sum(int a, int b) {
    return a + b;
}

int main() {
    int x = 5;
    // x и 10 — аргументы функции
    cout << sum(x, 10) << endl; // Выведет: 15
    return 0;
}

2. Способы передачи параметров

Способ Синтаксис Как работает Когда использовать
По значению void f(int x) Создаётся копия аргумента. Оригинал не меняется. Для простых типов (int, double, char, bool).
По ссылке void f(int& x) Передаётся сам оригинал без копирования. Изменения влияют на исходную переменную. Когда нужно изменить переменную внутри функции.
По константной ссылке void f(const string& s) Передаётся оригинал без копирования, но менять его запрещено. Для тяжёлых объектов (string, vector) только для чтения.
По указателю void f(int* p) Передаётся адрес в памяти. Может принимать nullptr. Для работы с динамической памятью, массивами или опциональными параметрами. 
#include <iostream>
#include <string>
using namespace std;

void byValue(int x) { x = 100; }
void byRef(int& x) { x = 100; }
void byConstRef(const string& text) { cout << text << endl; }

int main() {
    int num = 10;
    byValue(num); // num остаётся 10
    byRef(num);   // num становится 100

    string msg = "Hello";
    byConstRef(msg); // Без лишнего копирования строки
    return 0;
}

3. Аргументы по умолчанию

  • Параметру можно задать стандартное значение на случай, если аргумент не передан при вызове.
  • Параметры со значениями по умолчанию должны располагаться строго справа (в конце списка параметров).
#include <iostream>
using namespace std;

// Правильно: b имеет значение по умолчанию и стоит в конце
int power(int base, int exp = 2) {
    int res = 1;
    for (int i = 0; i < exp; i++) res *= base;
    return res;
}

int main() {
    cout << power(5) << endl;    // Используется exp = 2 -> 25
    cout << power(5, 3) << endl; // Используется exp = 3 -> 125
    return 0;
}
Если функция имеет прототип (объявление перед main), значение по умолчанию указывается только в прототипе, а не в определении.

4. Передача массивов в функцию

  • Обычный массив при передаче в функцию «распадается» (decay) на указатель на его первый элемент.
  • Функция не знает размер переданного массива, поэтому размер всегда передаётся отдельным параметром.
#include <iostream>
using namespace std;

// Массив передаётся по указателю (изменения внутри меняют исходный массив)
void printArray(const int arr[], int size) {
    for (int i = 0; i < size; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}

int main() {
    int numbers[] = {10, 20, 30, 40};
    printArray(numbers, 4);
    return 0;
}
