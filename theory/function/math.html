C++ — Вбудовані функції

1. Вбудовані математичні функції (<cmath>)

Для використання математичних функцій у C++ підключають бібліотеку #include <cmath>

Функція Що робить Приклад Результат
pow(x, y) Підношення до степеня (xy) pow(5, 2) 25.0 (тип double)
sqrt(x) Квадратний корінь (√x) sqrt(16.0) 4.0 (тип double)
abs(x) / fabs(x) Модуль числа (|x|) abs(-7) 7
round(x) Округлення до найближчого цілого round(3.7) 4.0
floor(x) / ceil(x) Округлення вниз / вгору floor(3.7) / ceil(3.1) 3.0 / 4.0

2. Приклад використання функції pow()

Нижче наведено робочий приклад програми C++, яка підключає бібліотеку <cmath> та обчислює значення xy:

#include <iostream>
#include <cmath> // Підключення бібліотеки математичних функцій

int main() {
    double base = 5.0;
    double exponent = 3.0;
    
    // Використання функції pow()
    double result = std::pow(base, exponent);
    
    std::cout << base << " у степені " << exponent << " дорівнює " << result << std::endl;
    
    return 0;
}
