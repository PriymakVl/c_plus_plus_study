Логічний тип (bool)

Тип bool може мати лише два значення: true (істина) або false (хибність).

#include <iostream>
using namespace std;

int main() {
    bool isStudent = true;
    bool hasGraduated = false;

    cout << "isStudent: " << isStudent << endl; // Виведе 1
