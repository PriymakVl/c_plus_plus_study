C++ — Класифікація типів даних

1. Класифікація типів даних

У C++ кожна змінна має чітко визначений тип даних. Тип визначає:

  • скільки пам'яті займає змінна;
  • які значення вона може зберігати;
  • які операції над нею дозволені.
Категорія Типи C++ Опис
Цілочисельні int, short, long, long long Цілі числа (додатні, від'ємні, нуль)
Дійсні (дробові) float, double Числа з плаваючою крапкою
Символьні char, wchar_t Поодинокі символи у ASCII / Unicode
Логічні bool Логічні значення: true (1) або false (0)
Рядкові string Текстові рядки (з бібліотеки <string>)
