1. Класифікація типів даних

У C++ кожна змінна має чітко визначений тип даних. Тип визначає, скільки пам'яті займає змінна, які значення вона може зберігати та які операції над нею дозволені.

КатегоріяТипи C++Опис
Цілочисельніint, short, long, long longЦілі числа (додатні, від'ємні, нуль)
Дійсні (дробові)float, doubleЧисла з плаваючою крапкою
Символьніchar, wchar_tПоодинокі символи у ASCII / Unicode
ЛогічніboolЛогічні значення: true (1) або false (0)
РядковіstringТекстові рядки (з бібліотеки <string>)

Пам'ятай: C++ — це мова зі статичною типізацією. Тип змінної вказується при створенні й не може змінюватися під час виконання програми.

2. Цілочисельні типи та модифікатори

Для роботи з цілими числами використовуються різні типи залежно від необхідного діапазону значень:

ТипПриблизний розмірДіапазон (signed)
short2 байтивід -32 768 до 32 767
int4 байтивід -2 147 483 648 до 2 147 483 647
long long8 байтіввід -9*1018 до 9*1018

Модифікатори знаку

  • signed — за замовчуванням. Зберігає від'ємні та додатні числа.
  • unsigned — зберігає тільки додатні числа і нуль, за рахунок чого подвоює верхню межу!
unsigned int studentsCount = 30; // Не може бути від'ємним!
unsigned char age = 15;          // Від 0 до 255
Зауваження: Якщо записати в unsigned від'ємне число, станеться переповнення, і змінна отримає величезне додатне значення!

3. Дійсні числа (плаваюча крапка)

Для збереження дробових чисел використовують float та double.

ТипРозмірТочністьПриклад
float4 байти~6-7 знаків після крапки3.14159f
double8 байтів~15-17 знаків після крапки3.141592653589793
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    float f = 1.23456789f;
    double d = 1.23456789012345;

    cout << setprecision(10);
    cout << "Float:  " << f << endl; // Втрачає точність в кінці
    cout << "Double: " << d << endl; // Зберігає точність

    return 0;
}

Порада: В реальних проєктах та задачах за замовчуванням слід використовувати double, оскільки він надає достатню точність для обчислень.

4. Символи та рядки

Тип char зберігає один символ і записується в одинарних лапках. Кожен символ всередині комп'ютера зберігається як числовий код ASCII.

char letter = 'A';
char symbol = '$';

cout << letter << " має код " << int(letter) << endl; // Виведе: A має код 65

Рядки (string)

Для роботи з текстом використовується клас string із бібліотеки <string>. Текст завжди береться у подвійні лапки.

#include <iostream>
#include <string>
using namespace std;

int main() {
    string greeting = "Hello, World!";
    cout << greeting << endl;
    return 0;
}

6. Оператор sizeof

Оператор sizeof дозволяє дізнатися, скільки байтів у пам'яті займає конкретний тип або змінна на вашому комп'ютері.

#include <iostream>
using namespace std;

int main() {
    cout << "sizeof(char) = " << sizeof(char) << " byte" << endl;
    cout << "sizeof(int) = " << sizeof(int) << " bytes" << endl;
    cout << "sizeof(double) = " << sizeof(double) << " bytes" << endl;
    cout << "sizeof(bool) = " << sizeof(bool) << " byte" << endl;

    return 0;
}
Інтерактивна перевірка. Який тип займає найбільше пам'яті?

7. Приведення типів (Type Casting)

Приведення типів — це перетворення значення одного типу в інший.

1. Неявне (автоматичне)

int a = 5;
double b = a; // a автоматично перетворюється на 5.0

double x = 9.99;
int y = x;    // Автоматично відкидає дробову частину! y стане 9

2. Явне перетворення (static_cast)

Рекомендований стиль у сучасній C++:

int num = 7, den = 2;
double result = static_cast<double>(num) / den; // Результат 3.5 замість 3

8. Практика — задачі на типи даних

Завдання 1. ASCII код. Напишіть програму, яка зчитує один символ і виводить його числовий код ASCII.
Рішення
#include <iostream>
using namespace std;

int main() {
    char ch;
    cout << "Enter character: ";
    cin >> ch;

    cout << "ASCII code: " << static_cast<int>(ch) << endl;

    return 0;
}
Завдання 2. Точне ділення. Ввести два цілих числа та знайти їх точну частку (з дробовою частиною).
Рішення
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cout << "Enter two integers: ";
    cin >> a >> b;

    if (b != 0) {
        double div = static_cast<double>(a) / b;
        cout << "Result: " << div << endl;
    } else {
        cout << "Error: Division by zero!" << endl;
    }

    return 0;
}
Завдання 3. Температура. Перетворити температуру з градусів Цельсія у Фаренгейт. Формула: F = C * 1.8 + 32.
Рішення
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double celsius;
    cout << "Celsius: ";
    cin >> celsius;

    double fahrenheit = celsius * 1.8 + 32;

    cout << fixed << setprecision(1);
    cout << "Fahrenheit: " << fahrenheit << endl;

    return 0;
}
