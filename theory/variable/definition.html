Змінні у C++ — Оголошення та ініціалізація

1. Оголошення та ініціалізація змінної

Змінна — це іменована область пам'яті для збереження даних. У C++ обов'язково спочатку вказується тип, а потім ім'я.

// Створення (оголошення)
int age;

// Присвоєння значення (ініціалізація)
age = 15;

// Створення та надання значення в один рядок:
double price = 99.99;
string name = "Олексій";
Пояснення: Оператор = — це не рівність, а присвоєння. Обчислюється вираз праворуч і записується у змінну ліворуч.
