1. Оголошення та ініціалізація змінної

Змінна — це іменована область пам'яті для збереження даних. У C++ обов'язково спочатку вказується тип, а потім ім'я.

// Створення (оголошення)
int age;

// Присвоєння значення (ініціалізація)
age = 15;

// Створення та надання значення в один рядок:
double price = 99.99;
string name = "Олексій";
Пояснення: Оператор = — це не рівність, а присвоєння. Обчислюється вираз праворуч і записується у змінну ліворуч.

2. Символи та правила в назві змінної

Ім'я змінної (ідентифікатор) підпорядковується чітким правилам мови C++:

Що можна використовуватиПриклади дозволених імен
  • Латинські літери: a-z, A-Z
  • Цифри: 0-9 (але НЕ на початку!)
  • Знак підкреслення: _
 user_age, score2, _total, playerHealth

Критичні правила та обмеження:

  1. Не можна починати з цифри: 1player — ПОМИЛКА! (Правильно: player1).
  2. Спеціальні символи заборонені: Пробіли, дефіси, розділові знаки, знаки $, %, @, #, ! — НЕ МОЖНА. (user-age — помилка, використовуйте user_age).
  3. Кирилиця та інші алфавіти: Використовувати не бажано (і в багатьох стандартах заборонено). Називайте змінні англійською.
  4. Чутливість до регістру: speed, Speed та SPEED — це три різні змінні!
  5. Ключові (зарезервовані) слова: Не можна називати змінну int, double, class, return, using тощо.

4. Як вставити змінну в рядок

У C++ є кілька основних способів виведення змінних разом із текстом та поєднання їх у єдиний рядок.

Спосіб 1: Потік std::cout (Найпростіший та найуживаніший)

Оператор << дозволяє «зліплювати» текст у подвійних лапках і змінні послідовно:

#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Анна";
    int age = 16;
    double score = 98.5;

    // Вставка кількох змінних у текст
    cout << "Привіт, мене звати " << name << ", мені " << age << " років!" << endl;
    cout << "Мій бал: " << score << " зі 100." << endl;

    return 0;
}

Спосіб 2: Конкатенація рядків через `+` (тільки для string)

Якщо потрібно створити новий рядок у пам'яті, з'єднавши текст та інші змінні:

#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Іван";
    int level = 5;

    // Щоб додати число до string, його треба перетворити за допомогою to_string()
    string message = "Гравець " + name + " досяг рівня " + to_string(level) + "!";
    
    cout << message << endl;
    return 0;
}
Зверніть увагу: Числові змінні (int, double) не можна просто так додавати до `string` через `+`. Потрібно обов'язково використовувати to_string(variable)!

Спосіб 3: Сучасне форматування std::format (C++20)

У сучасній мові C++20 додано аналог f-string з Python чи string.Format з C#:

#include <iostream>
#include <format> // Потрібен стандарт C++20
using namespace std;

int main() {
    string item = "Яблуко";
    int count = 3;
    
    // Вставка змінних у місця фігурних дужок {}
    string text = format("Ви купили {} шт. товару: {}.", count, item);
    cout << text << endl;

    return 0;
}

5. Практичні завдання

Завдання 1. Виправлення помилок у назвах. Які з цих назв змінних написані з помилкою і чому?

1st_place, total-sum, user_age, double, myScore

Перевірити відповідь
  • 1st_place — Помилка: починається з цифри.
  • total-sum — Помилка: дефіс не дозволений (треба використовувати підкреслення total_sum).
  • user_age — Правильно!
  • double — Помилка: це зарезервоване слово (тип даних).
  • myScore — Правильно (стиль camelCase).
Завдання 2. Вставка в рядок. Складіть програму, де оголошено змінні city (город), temp (температура), і виведіть фразою: "Сьогодні у місті [city] температура [temp] градусов."
Показати C++ код 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string city = "Київ";
    int temp = 22;

    cout << "Сьогодні у місті " << city << " температура " << temp << " градусів." << endl;

    return 0;
}
Завдання 3. Конкатенація через to_string. Запишіть у змінну fullInfo рядок із назвою товару та його ціною.
Показати C++ код 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string title = "Ноутбук";
    double price = 25500.50;

    string fullInfo = "Товар: " + title + " | Ціна: " + to_string(price) + " грн";
    cout << fullInfo << endl;

    return 0;
}
