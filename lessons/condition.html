1. Що таке умовний оператор?

Умовний оператор (галуження) дозволяє програмі приймати рішення: виконувати один блок коду чи інший залежно від того, чи є умова істинною (true) або хибною (false).

Синтаксис повної форми

if (умова) {
    // код, якщо умова true
} else {
    // код, якщо умова false
}

Синтаксис неповної форми

if (умова) {
    // код, якщо умова true
}
Головна помилка початківців C++: Не плутайте оператор присвоєння = і перевірку на рівність ==. Вираз if (x = 5) не перевіряє значення, а присвоює $x$ значення 5 і зазвичай повертає true!

Приклад повної форми

#include <iostream>
using namespace std;

int main() {
    int age;
    cout << "Введіть ваш вік: ";
    cin >> age;

    if (age >= 18) {
        cout << "Доступ дозволено" << endl;
    } else {
        cout << "Доступ обмежено" << endl;
    }

    return 0;
}

3. Логічні оператори: &&, ||, !

Якщо необхідно перевірити кілька умов одночасно, використовують логічні оператори:

ОператорНазваОписПриклад
&&Логічне І (AND)Істинно, коли обидві умови істинні(x > 0) && (x < 10)
||Логічне АБО (OR)Істинно, коли хоча б одна умова істинна(age < 6) || (age > 65)
!Логічне НЕ (NOT)Змінює значення на протилежне!(x == 0)
Ліниві обчислення (Short-circuiting): У C++ якщо у виразі A && B перша умова A є false, друга умова B навіть не обчислюється. У виразі A || B якщо A є true, B також ігнорується.
Швидка практика. Напишіть умову для перевірки, чи знаходиться число $x$ у діапазоні від 10 до 50 включно. 
if (x >= 10 && x <= 50) {
    cout << "Число в діапазоні";
}

4. Перемикач switch та тернарний оператор

Коли потрібно перевірити одну змінну на збіг з багатьма конкретними значеннями, зручно використовувати switch.

int day = 3;

switch (day) {
    case 1:
        cout << "Понеділок";
        break;
    case 2:
        cout << "Вівторок";
        break;
    case 3:
        cout << "Середа";
        break;
    default:
        cout << "Некоректний день";
}
Увага! Обов'язково ставте break; у кінці кожного блоку case, інакше програма продовжить виконувати код наступних варіантів!

Тернарний оператор (скорочений if-else)

// Синтаксис: умова ? вираз_1 : вираз_2;
int max = (a > b) ? a : b;

5. Практика — пишемо самі

Завдання 1. Парне чи непарне. Користувач вводить ціле число. Програма визначає, чи є воно парним.
Код та розбір
#include <iostream>
using namespace std;

int main() {
    int num;
    cout << "Введіть число: ";
    cin >> num;

    if (num % 2 == 0) {
        cout << "Число парне" << endl;
    } else {
        cout << "Число непарне" << endl;
    }

    return 0;
}

Пояснення: Оператор % повертає остачу від ділення. Якщо остача від ділення на 2 дорівнює 0 — число парне.

Завдання 2. Пошук максимуму з двох чисел. Ввести два числа та вивести більше з них.
Код рішення
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cout << "Введіть два числа: ";
    cin >> a >> b;

    if (a > b) {
        cout << "Максимум: " << a << endl;
    } else {
        cout << "Максимум: " << b << endl;
    }

    return 0;
}
Завдання 3. Оцінка за балами. Ввести бал учня (1-12). Якщо бал $\ge 10$, вивести «Відмінно», якщо $\ge 7$ — «Добре», інакше — «Потрібно попрацювати».
Код з else if
#include <iostream>
using namespace std;

int main() {
    int score;
    cout << "Введіть ваш бал (1-12): ";
    cin >> score;

    if (score >= 10) {
        cout << "Відмінно" << endl;
    } else if (score >= 7) {
        cout << "Добре" << endl;
    } else {
        cout << "Потрібно попрацювати" << endl;
    }

    return 0;
}
Завдання 4. Знижка на покупку. Ввести суму покупки. Якщо сума перевищує 1000 грн, надати знижку 10% та вивести кінцеву суму.
Рішення
#include <iostream>
using namespace std;

int main() {
    double sum, total;
    cout << "Введіть суму покупки: ";
    cin >> sum;

    if (sum > 1000) {
        total = sum * 0.9;
        cout << "Вам надано знижку 10%!" << endl;
    } else {
        total = sum;
    }

    cout << "До сплати: " << total << " грн" << endl;
    return 0;
}
Завдання 5. Існування трикутника. Дано три сторони $a, b, c$. Перевірити, чи існує трикутник з такими сторонами (кожна сторона має бути меншою за суму двох інших).
Рішення
#include <iostream>
using namespace std;

int main() {
    double a, b, c;
    cout << "Введіть 3 сторони: ";
    cin >> a >> b >> c;

    if ((a + b > c) && (a + c > b) && (b + c > a)) {
        cout << "Трикутник існує" << endl;
    } else {
        cout << "Трикутник НЕ існує" << endl;
    }

    return 0;
}
