1. Вбудовані математичні функції (<cmath>)

Функція — це ізольований блок коду, який приймає аргументи, виконує обчислення та **повертає результат**. Для використання математичних функцій у C++ підключають бібліотеку #include <cmath> (а для рядків — <string>).

2. Створення власних функцій (Return type)

У C++ тип значення, яке повертає функція, вказується **перед її ім'ям**. Для повернення результату використовується оператор return.

ТипРезультату НазваФункції(Тип1 параметр1, Тип2 параметр2) {
    // локальні змінні (за потреби)
    return результат; // повернення значення
}

Приклад: Функція обчислення площі прямокутника

#include <iostream>
using namespace std;

// Оголошення та визначення функції
double getArea(double a, double b) {
    return a * b; // повертаємо результат обчислення
}

int main() {
    double x, y;
    cout << "Введіть сторони: ";
    cin >> x >> y;
    
    double area = getArea(x, y); // виклик функції
    cout << "Площа: " << area << endl;
    
    return 0;
}

Запам'ятай: Виконання функції припиняється одразу після того, як спрацює оператор return.

3. Функції, що нічого не повертають (void)

Якщо функція виконує дію (наприклад, друкує текст чи очищує екран) і не повинна повертати значення, її типом повернення вказують void (аналог процедур у Pascal).

Функція зі значенням

int cube(int x) {
    return x * x * x;
}

// Виклик у виразі або виводі:
int ans = cube(3);
cout << cube(3);

Функція типа void

void printLine() {
    cout << "--------------------" << endl;
}

// Виклик як окрема команда:
printLine();
Для вчителя. Поясніть різницю: функцію із типом (int, double) можна підставити у cout << cube(3) або вираз, а void-функцію викликають тільки як окремий оператор.

4. Передача за значенням та за посиланням (&)

За замовчуванням параметри передаються за значенням (створюється копія). Щоб функція могла **змінити значення оригінальної змінної**, використовують амперсанд & (передача за посиланням).

void swap(int &a, int &b) { // & дозволяє змінювати оригінали
    int temp = a;
    a = b;
    b = temp;
}
Тип передачіСинтаксисОписЗмінює оригінал?
За значенням(int a)Передається копія данихНі
За посиланням(int &a)Передається адреса самої змінноїТак
Константне посилання(const string &s)Передача без копіювання (швидко), але без права зміниНі

5. Локальні та глобальні змінні

Змінні, оголошені поза будь-якою функцією, є **глобальними**. Змінні, оголошені всередині функції — **локальними** (існують тільки під час виконання цієї функції та всередині її блоку {}).

#include <iostream>
using namespace std;

int g = 10; // Глобальна змінна

void test() {
    int l = 5; // Локальна змінна
    cout << g << endl; // Глобальні змінні видно всюди
}

int main() {
    test();
    // cout << l; -> ПОМИЛКА КОМПІЛЯЦІЇ! Змінна 'l' тут не існує.
    return 0;
}

8. Підсумкова програма

Напишіть програму, яка містить функцію int power(int base, int exp) для обчислення ступеня числа (наприклад, $2^3 = 8$).

Рішення для вчителя
#include <iostream>
using namespace std;

int power(int base, int exp) {
    int res = 1;
    for (int i = 0; i < exp; i++) {
        res *= base;
    }
    return res;
}

int main() {
    int a, b;
    cout << "Основа: "; 
    cin >> a;
    cout << "Показник: "; 
    cin >> b;
    
    cout << "Результат: " << power(a, b) << endl;
    return 0;
}

Що перевіряємо: функція з кількома параметрами, значення, що повертається через return, локальні змінні res, i, цикл for та виклик з main().
