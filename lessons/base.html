1. Будова програми

#include <iostream>  // Бібліотека для введення та виведення

using namespace std;

int main() {         // Головна функція, з якої починається виконання
    int age = 14;    // Оголошення та ініціалізація змінної
    
    cout << "Age: " << age << endl;
    
    return 0;        // Успішне завершення програми
}
ЕлементЩо означає
#include <iostream>підключення бібліотеки для роботи з потоками cin та cout
using namespace std;дозволяє використовувати cout замість std::cout
int main() { ... }головна функція програми, весь основний код пишеться всередині
return 0;сигнал системі про те, що програма завершилася без помилок
;крапка з комою завершує кожну інструкцію (команду)

Запам'ятай: C++ чутливий до регістру! Символи main, int та INT для нього є абсолютно різними речами.

2. Змінні

Змінна — це іменована область пам'яті для збереження даних. Синтаксис оголошення:

тип ім'я_змінної;

Кілька змінних одного типу можна оголосити через кому, а також одразу надати їм значення (ініціалізувати):

int a = 10, b = 20, sum;
string name = "Max";

Присвоєння значення

a = 15;
name = "Alex";
Пояснення синтаксису. У C++ спочатку вказується тип, а потім ім'я. Оператор = означає «присвоїти значення» (записати те, що праворуч, у змінну ліворуч). Наприклад, int age = 14; створює цілочисельну змінну age зі значенням 14.
Швидка практика. Оголоси змінні studentName, age і height для імені, віку та зросту в C++. 
string studentName = "John";
int age = 15;
double height = 1.75;

4. Виведення та введення

Виведення (cout)

cout << "Hello";
cout << "Hello" << endl;

cout відповідає за виведення. endl (або "\n") виконує перехід на новий рядок.

Введення (cin)

cin >> age;

cin чекає, поки користувач введе значення з клавіатури, і зберігає його у змінну.

Повна програма

#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    int age;

    cout << "Enter your name: ";
    cin >> name;

    cout << "Enter your age: ";
    cin >> age;

    cout << "Hello, " << name << "!" << endl;
    cout << "You are " << age << " years old." << endl;

    return 0;
}
Для вчителя. Зверніть увагу учнів на напрямок стрілок: у cout стрілки спрямовані ВІД даних ДО виводу (<<), а у cin — ВІД вводу ДО змінної (>>).

5. Арифметика

ОпераціяC++Приклад
додавання+a + b
віднімання-a - b
множення*a * b
ділення/7 / 2 (для int поверне 3!)
остача від ділення%7 % 2 = 1 (тільки для цілих)
#include <iostream>
using namespace std;

int main() {
    int a, b;

    cout << "a = ";
    cin >> a;
    cout << "b = ";
    cin >> b;

    cout << "Sum = " << a + b << endl;
    cout << "Difference = " << a - b << endl;
    cout << "Product = " << a * b << endl;
    cout << "Integer division = " << a / b << endl;
    cout << "Remainder = " << a % b << endl;

    return 0;
}

Особливість ділення: Якщо обидва операнди є int, операція / робить цілочисельне ділення (дробова частина відкидається). Щоб отримати точний результат, хоча б одна змінна має бути double.

6. Форматування дробових чисел

#include <iostream>
#include <iomanip> // Потрібно для setprecision
using namespace std;

int main() {
    double price = 12.34567;
    
    cout << fixed << setprecision(2);
    cout << price << endl; // Виведе: 12.35
    
    return 0;
}

fixed разом із setprecision(2) означає: виводити число з 2 цифрами після десяткової крапки.

7. Практика — пишемо самі

Завдання 1. Візитівка. Користувач вводить ім'я та вік. Програма вітається і показує дані.
Код для вчителя
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    int age;

    cout << "Name: ";
    cin >> name;
    cout << "Age: ";
    cin >> age;

    cout << "Hello, " << name << "!" << endl;
    cout << "Age: " << age << endl;

    return 0;
}
Завдання 2. Сума двох чисел. Ввести два цілі числа та знайти їх суму.
Код для вчителя + пояснення
#include <iostream>
using namespace std;

int main() {
    int a, b, result;

    cin >> a >> b;
    result = a + b;
    
    cout << "Result = " << result << endl;

    return 0;
}

result = a + b; — спочатку C++ обчислює вираз праворуч від =, а потім зберігає значення у result.

Завдання 3. Прямокутник. Ввести довжину і ширину. Обчислити площу та периметр.
Код для вчителя
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double a, b, area, perimeter;

    cout << "Length: ";
    cin >> a;
    cout << "Width: ";
    cin >> b;

    area = a * b;
    perimeter = 2 * (a + b);

    cout << fixed << setprecision(2);
    cout << "Area = " << area << endl;
    cout << "Perimeter = " << perimeter << endl;

    return 0;
}
Завдання 4. Вік наступного року. Учень вводить свій вік. Програма показує, скільки років йому буде наступного року.
Рішення
#include <iostream>
using namespace std;

int main() {
    int age;

    cout << "Your age: ";
    cin >> age;
    
    cout << "Next year you will be " << age + 1 << endl;

    return 0;
}
Завдання 5. Секунди. Ввести кількість хвилин та перевести її в секунди.
Рішення
#include <iostream>
using namespace std;

int main() {

    cout << "Minutes: ";

9. Підсумкова програма

Напишіть мініпрограму «Покупка»: користувач вводить назву товару, ціну та кількість. Програма обчислює загальну вартість.

Рішення для вчителя
#include <iostream>
#include <string>
#include <iomanip>
using namespace std;

int main() {
    string productName;
    double price, total;
    int quantity;

    cout << "Product: ";
    cin >> productName;

    cout << "Price: ";
    cin >> price;

    cout << "Quantity: ";
    cin >> quantity;

    total = price * quantity;

    cout << fixed << setprecision(2);
    cout << "Product: " << productName << endl;
    cout << "Total: " << total << endl;

    return 0;
}

Що перевіряємо: string, int, double, cin, cout, присвоєння, множення та форматування виводу.
