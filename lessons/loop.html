Цикли в C++

Інтерактивний урок з вивчення циклічних конструкцій: for, while та do-while.

1. Що таке цикл?

Цикл — це конструкція мови, яка дозволяє повторювати виконання одного й того ж блоку коду декілька разів.

Запам'ятай: У C++ є 3 основні види циклів:

  • for — цикл із лічильником (найчастіше використовується, коли кількість повторень відома заздалегідь).
  • while — цикл із передумовою (перевіряє умову ПЕРЕД виконанням).
  • do-while — цикл із постумовою (перевіряє умову ПІСЛЯ виконання).

2. Цикл із лічильником (FOR)

Використовується, коли ми точно знаємо, скільки разів має виконатися цикл або з яким кроком потрібно змінювати змінну.

Синтаксис (прямий порядок):

for (int i = 1; i <= 5; i++) {
    std::cout << "Крок: " << i << std::endl;
}

Синтаксис (зворотний порядок):

for (int i = 5; i >= 1; i--) {
    std::cout << "Зворотний відлік: " << i << std::endl;
}
Пояснення синтаксису. Заголовок циклу for (ініціалізація; умова; крок) складається з трьох частин, розділених крапкою з комою ;. Якщо тіло циклу містить кілька команд, їх об'єднують фігурними дужками { ... }.
Швидка практика. Напиши заголовок циклу for, який лічить від 10 до 20 включно. 
for (int i = 10; i <= 20; i++)

3. Цикл із передумовою (WHILE)

Цикл виконується поки умова є істинною (true). Умова перевіряється перед початком кожної ітерації.

#include <iostream>
using namespace std;

int main() {
    int i = 1;
    while (i <= 5) {
        cout << "i = " << i << endl;
        i++; // Обов'язково змінюємо умову, інакше цикл буде нескінченним!
    }
    return 0;
}

Важливо: Якщо умова спочатку хибна (false), тіло циклу жодного разу не виконається!

4. Цикл із постумовою (DO-WHILE)

Тіло циклу спочатку виконується, а потім перевіряється умова. Повторення триває доти, поки умова є істинною (true).

#include <iostream>
#include <string>
using namespace std;

int main() {
    string password;
    do {
        cout << "Введіть пароль: ";
        cin >> password;
    } while (password != "1234");
    
    cout << "Доступ дозволено!" << endl;
    return 0;
}
Зверни увагу:
  • Тіло циклу do-while завжди виконується як мінімум 1 раз.
  • Наприкінці після дужки з умовою while (умова) обов'язково ставиться крапка з комою ;!

5. Порівняння типів циклів

ЦиклКоли використовуватиКількість повторів
forВідома точна кількість повторень або конкретний крокФіксована (0 або більше)
whileКількість повторів невідома, перевірка ДО діїВід 0 до нескінченності
do-whileПотрібно хоча б 1 раз виконати дію (наприклад, перевірка введення)Від 1 до нескінченності

6. Практика — пишемо самі

Завдання 1. Таблиця множення. Вивести таблицю множення на 5 для чисел від 1 до 10 за допомогою циклу for.
Код для вчителя
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        cout << "5 x " << i << " = " << 5 * i << endl;
    }
    return 0;
}
Завдання 2. Сума чисел. Обчислити суму всіх цілих чисел від 1 до N (число N вводить користувач).
Код для вчителя
#include <iostream>
using namespace std;

int main() {
    int n, sum = 0;
    cout << "Введіть N: ";
    cin >> n;
    
    for (int i = 1; i <= n; i++) {
        sum += i;
    }
    
    cout << "Сума від 1 до " << n << " = " << sum << endl;
    return 0;
}
Завдання 3. Захист від введення. Просити користувача ввести додатне число. Повторювати запит, поки число ≤ 0.
Рішення
#include <iostream>
using namespace std;

int main() {
    int num;
    do {
        cout << "Введіть число більше 0: ";
        cin >> num;
    } while (num <= 0);
    
    cout << "Дякуємо! Ви ввели: " << num << endl;
    return 0;
}
