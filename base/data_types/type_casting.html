C++ — Приведення типів (Type Casting)

1. Що таке приведення типів

  • Приведення типів — це перетворення значення одного типу в інший.

2. Неявне (автоматичне) приведення

  • Виконується компілятором автоматично під час присвоєння або обчислень.
  • При перетворенні дробового числа в ціле дробова частина відкидається.
int a = 5;
double b = a; // a автоматично перетворюється на 5.0

double x = 9.99;
int y = x;    // Автоматично відкидає дробову частину! y стане 9

3. Явне перетворення (static_cast)

  • Рекомендований стиль явного перетворення типів у сучасному C++.
int num = 7, den = 2;
double result = static_cast<double>(num) / den; // Результат 3.5 замість 3
