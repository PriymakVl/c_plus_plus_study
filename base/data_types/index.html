C++ — Типи даних

# Name Remark
1 Класифікація типів даних Основні категорії типів у C++, розмір у пам'яті та дозволені операції
2 Цілочисельні та дійсні типи даних Типи short, int, long long, float, double та модифікатори signed / unsigned
3 Символи та рядки Робота з поодинокими символами (char, коди ASCII) та текстовими рядками (string)
4 Логічний тип (bool) Логічні значення true та false, форматування виводу через boolalpha
5 Оператор sizeof Визначення розміру пам'яті в байтах, який займає конкретний тип або змінна
6 Приведення типів (Type Casting) Неявне автоматичне перетворення типів та явне перетворення через static_cast
