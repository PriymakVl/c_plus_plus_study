C++ — Символи та рядки

1. Символьний тип (char)

  • Тип char зберігає один символ і записується в одинарних лапках.
  • Кожен символ всередині комп'ютера зберігається як числовий код ASCII.
char letter = 'A';
char symbol = '$';

cout << letter << " має код " << int(letter) << endl; // Виведе: A має код 65

2. Рядки (string)

  • Для роботи з текстом використовується клас string із бібліотеки <string>.
  • Текст завжди береться у подвійні лапки.
#include <iostream>
#include <string>
using namespace std;

int main() {
    string greeting = "Hello, World!";
    cout << greeting << endl;
    return 0;
}
