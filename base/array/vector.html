C++ — Динамічні масиви (std::vector)

1. Що таке std::vector та як його оголосити

std::vector — це динамічний масив із бібліотеки C++ Standard Template Library (STL), який може змінювати свій розмір під час виконання програми.

Для використання вектора необхідно підключити заголовочний файл <vector>.

Синтаксис оголошення вектора:

#include <vector>

std::vector<тип_даних> ім_я_вектора;
Приклад Опис
vector<int> numbers; Порожній вектор для цілих чисел
vector<double> temp(5); Вектор з 5 дробових чисел (заповнений нулями)
vector<string> words; Порожній вектор для текстових рядків
Важливо! На відміну від звичайного масиву, розмір std::vector не обов'язково задавати заздалегідь — він може рости при додаванні нових елементів.

2. Ініціалізація та додавання елементів

Створювати вектор та додавати до нього нові значення можна різними способами:

#include <iostream>
#include <vector>
using namespace std;

int main() {
    // Ініціалізація списком
    vector<int> numbers = {10, 20, 30};

    // Додавання елементів у кінець вектора за допомогою push_back()
    numbers.push_back(40); // Вектор тепер містить {10, 20, 30, 40}
    numbers.push_back(50); // {10, 20, 30, 40, 50}

    // Створення вектора з 4 однакових елементів (значення 7)
    vector<int> sameValues(4, 7); // {7, 7, 7, 7}

    return 0;
}

3. Доступ до елементів та основні методи

Доступ до елементів виконується через квадратні дужки [] або метод .at():

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> vec = {10, 20, 30};

    cout << "Перший елемент: " << vec[0] << endl; // 10
    cout << "Кількість елементів: " << vec.size() << endl; // 3

    vec.pop_back(); // Видаляє останній елемент (30)
    cout << "Новий розмір: " << vec.size() << endl; // 2

    // Метод .at() перевіряє вихід за межі вектора
    cout << "Другий елемент: " << vec.at(1) << endl; // 20

    return 0;
}
Запам'ятай: Метод vec.at(index) безпечніший за vec[index], оскільки генерація помилки видачі гарантує контроль виходу за межі дозволеного діапазону.
