C++ — Масиви та контейнери

# Name Remark
1 C++ — Базові масиви Поняття одномірного масиву, синтаксис оголошення, повна, автоматична й часткова ініціалізація та доступ до елементів за індексом
2 C++ — Масиви та цикли Перебір елементів масиву циклом for, введення значень з клавіатури через cin, обчислення суми та пошук максимуму
3 C++ — Двовимірні масиви Оголошення та ініціалізація двовимірних масивів (матриць), доступ за індексами рядка й стовпчика та обхід вкладеними циклами for
4 C++ — Динамічні масиви (std::vector) Підключення <vector>, оголошення та ініціалізація динамічного масиву, додавання й видалення елементів через push_back() та pop_back(), безпечний доступ через .at()
5 C++ — Двозв'язні списки (std::list) Підключення <list>, особливості двозв'язного списку, додавання та видалення елементів з обох кінців (push_front(), push_back(), pop_front(), pop_back()) та обхід елементів
