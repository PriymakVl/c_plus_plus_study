C++ — Функции и алгоритмы для работы с массивами

В C++ для работы с обычными (статическими) массивами можно использовать встроенные функции, методы стандартной библиотеки и алгоритмы из <algorithm>. Рассмотрим основные инструменты для начинающих.

1. Получение размера массива

int arr[] = {10, 20, 30, 40, 50};

int size = sizeof(arr) / sizeof(arr[0]);
  • sizeof(arr) — размер всего массива в байтах.
  • sizeof(arr[0]) — размер одного элемента.
  • Деление позволяет получить количество элементов.

2. Функции для работы с массивами

Для использования подключаем заголовочный файл:

#include <algorithm>
Функция Назначение Пример
sort() Сортировка sort(arr, arr + size)
reverse() Обратный порядок reverse(arr, arr + size)
find() Поиск элемента find(arr, arr + size, 20)
count() Подсчёт элементов count(arr, arr + size, 10)
min_element() Минимальный элемент min_element(arr, arr + size)
max_element() Максимальный элемент max_element(arr, arr + size)
fill() Заполнение массива fill(arr, arr + size, 0)
copy() Копирование массива copy(arr, arr + size, dest)
replace() Замена значений replace(arr, arr + size, 10, 100)

3. Примеры использования

Сортировка массива:

#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int arr[] = {5, 2, 8, 1, 4};
    int size = 5;

    sort(arr, arr + size);

    for (int i = 0; i < size; i++) {
        cout << arr[i] << " ";
    }
}
Результат: 1 2 4 5 8

Поиск элемента:

int arr[] = {10, 20, 30, 40, 50};

int* result = find(arr, arr + 5, 30);

if (result != arr + 5) {
    cout << "Найден";
} else {
    cout << "Не найден";
}

Поиск минимального и максимального значения:

int arr[] = {15, 4, 28, 7, 12};

int min = *min_element(arr, arr + 5);
int max = *max_element(arr, arr + 5);

Заполнение массива:

int arr[5];

fill(arr, arr + 5, 10);

Все элементы получат значение 10.
