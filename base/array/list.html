C++ — Двозв'язні списки (std::list)

1. Що таке std::list та як його оголосити

std::list — це контейнер із бібліотеки C++ Standard Template Library (STL), який реалізує двозв'язний список.

Для використання списку необхідно підключити заголовочний файл <list>.

Синтаксис оголошення списку:

#include <list>

std::list<тип_даних> ім_я_списку;
Приклад Опис
list<int> numbers; Порожній список для цілих чисел
list<double> temp(5); Список з 5 дробових чисел (заповнений нулями)
list<string> words; Порожній список для текстових рядків
Важливо! На відміну від std::vector, елементи std::list розміщуються в пам'яті не послідовно, тому він підтримує швидку вставку та видалення елементів з обох кінців і з середини, але не підтримує доступ за індексом через [].

2. Ініціалізація та додавання елементів

Створювати список та додавати до нього нові значення можна різними способами (як на початок, так і в кінець):

#include <iostream>
#include <list>
using namespace std;

int main() {
    // Ініціалізація списком
    list<int> numbers = {10, 20, 30};

    // Додавання елементів у кінець списку
    numbers.push_back(40); // Список тепер містить {10, 20, 30, 40}

    // Додавання елементів на початок списку
    numbers.push_front(5); // Список тепер містить {5, 10, 20, 30, 40}

    // Створення списку з 4 однакових елементів (значення 7)
    list<int> sameValues(4, 7); // {7, 7, 7, 7}

    return 0;
}

3. Доступ до елементів та основні методи

Оскільки std::list не підтримує доступ за індексом, для роботи з першим та останнім елементами використовуються спеціальні методи:

#include <iostream>
#include <list>
using namespace std;

int main() {
    list<int> lst = {10, 20, 30};

    cout << "Перший елемент: " << lst.front() << endl; // 10
    cout << "Останній елемент: " << lst.back() << endl; // 30
    cout << "Кількість елементів: " << lst.size() << endl; // 3

    lst.pop_front(); // Видаляє перший елемент (10)
    lst.pop_back();  // Видаляє останній елемент (30)

    cout << "Новий розмір: " << lst.size() << endl; // 1
    cout << "Єдиний елемент: " << lst.front() << endl; // 20

    return 0;
}
Запам'ятай: Для обходу елементів std::list використовується діапазонний цикл for (int x : lst) або ітератори, оскільки виклики на зразок lst[0] викличуть помилку компіляції.
