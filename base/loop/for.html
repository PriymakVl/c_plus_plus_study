Цикл із лічильником (FOR)

Використовується, коли ми точно знаємо, скільки разів має виконатися цикл або з яким кроком потрібно змінювати змінну.

Синтаксис (прямий порядок):

for (int i = 1; i <= 5; i++) {
    std::cout << "Крок: " << i << std::endl;
}

Синтаксис (зворотний порядок):

for (int i = 5; i >= 1; i--) {
    std::cout << "Зворотний відлік: " << i << std::endl;
}
Пояснення синтаксису. Заголовок циклу for (ініціалізація; умова; крок) складається з трьох частин, розділених крапкою з комою ;. Якщо тіло циклу містить кілька команд, їх об'єднують фігурними дужками { ... }.
