C++ — Створення та використання функцій

1. Створення власних функцій (void та глобальні змінні)

Функція типу void не повертає значення.

Приклад: Функція з логікою лічильника

#include <iostream>

// Глобальна змінна
int count = 0;

// Функція з логікою лічильника
void counter() {
    
    // Збільшуємо значення на 1
    count++;
    
    // Виводимо поточне значення
    std::cout << count << std::endl;
}

int main() {
    // Виклики функції counter()
    counter();
    counter();
    counter();
    
    return 0;
}
Запам'ятай:
  • Глобальна змінна count оголошена поза функціями, тому вона доступна як всередині counter(), так і в main().
  • Кожен виклик функції counter() збільшує її значення на 1.

2. Функції, що повертають значення

Якщо функція має обчислити та повернути результат, замість void вказують тип даних, який вона повертає (наприклад, int, double). Для повернення результату використовується оператор return.

Приклад: Обчислення куба числа

#include <iostream>

// Функція обчислення куба числа
int cube(int x) {
    return x * x * x;
}

int main() {
    // Перший виклик з аргументом 3
    int result1 = cube(3);
    std::cout << "Куб числа 3: " << result1 << std::endl;
    
    // Другий виклик з аргументом 5 безпосередньо у виводі
    std::cout << "Куб числа 5: " << cube(5) << std::endl;
    
    return 0;
}
Запам'ятай:
  • Результат роботи функції, яка повертає значення, можна зберегти у змінну (наприклад, result1 = cube(3)).
  • Також результат можна відразу передати у std::cout для виводу на екран.
