C++ — Локальні та глобальні змінні

Локальні та глобальні змінні

Змінні, оголошені поза будь-якою функцією, є глобальними. Змінні, оголошені всередині функції — локальними (існують тільки під час виконання цієї функції та всередині її блоку {}).

#include <iostream>
using namespace std;

int g = 10; // Глобальна змінна

void test() {
    int l = 5; // Локальна змінна
    cout << g << endl; // Глобальні змінні видно всюди
}

int main() {
    test();
    // cout << l; -> ПОМИЛКА КОМПІЛЯЦІЇ! Змінна 'l' тут не існує.
    return 0;
}
