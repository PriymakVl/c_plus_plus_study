1. Робота з об'єктом cout (виведення даних)

Об'єкт cout (походить від Console Output) використовується для виведення інформації на екран консолі. Він працює в параграфі з бібліотекою <iostream>.

Ланцюжки виведення оператором <<

Оператор << можна використовувати багаторазово в одному рядку, об'єднуючи текст, змінні та вирази:

#include <iostream>
using namespace std;

int main() {
    int score = 100;
    string player = "Alex";

    // Ланцюжкове виведення
    cout << "Гравець " << player << " має " << score << " балів!" << endl;

    return 0;
}

Перехід на новий рядок: endl проти "\n"

Для перенесення курсора на новий рядок є два шляхи:

endlcout << "Привіт" << endl;Переносить рядок та очищає буфер виводу (Flush).

Порада: Для звичайних програм навчального рівня різниця непомітна, але у великих програмах "\n" працює дещо швидше за endl.

2. Робота з об'єктом cin (введення даних)

Об'єкт cin (походить від Console Input) зчитує дані, які користувач вводить з клавіатури, та записує їх у змінні.

#include <iostream>
using namespace std;

int main() {
    int age;
    cout << "Введіть ваш вік: "; // Спочатку підказка
    cin >> age;                 // Очікування введення

    cout << "Ваш вік: " << age << endl;
    return 0;
}

Зчитування кількох змінних поспіль

Можна зчитувати кілька значень поспіль через один об'єкт cin. Значення у консолі можна розділяти пробілами або кнопкою Enter:

int x, y, z;
cout << "Введіть три числа: ";
cin >> x >> y >> z; // Зчитує спочатку x, потім y, потім z
Важливо: cin >> пропускає пробіли, табуляції та символи переходу на новий рядок під час пошуку наступного значення!

3. Напрямок стрілок і правило пам'ятки

Початківці часто плутають << та >>. Запам'ятати їхній напрямок дуже легко, якщо уявити потік даних як стрілочки:

cout << data;   ➔   [ Змінна / Текст ] ➔ << ➔ [ Екран ]

Дані рухаються ВІД вашої програми ДО екрану консолі.

cin >> variable;   ➔   [ Клавіатура ] ➔ >> ➔ [ Змінна ]

Дані рухаються ВІД клавіатури користувача ВВСЕРЕДИНУ змінної.

4. Зчитування рядків (getline) та форматування чисел

1. Проблема cin >> string та розв'язок getline

Стандартний cin >> str читає рядок лише до першого пробілу. Якщо ввести "Тарас Шевченко", у змінну потрапить тільки "Тарас".

Щоб зчитати весь рядок із пробілами, використовують функцію getline(cin, variable):

#include <iostream>
#include <string>
using namespace std;

int main() {
    string fullName;
    cout << "Введіть ваше повне ім'я: ";
    getline(cin, fullName); // Зчитує весь рядок разом із пробілами

    cout << "Вітаємо, " << fullName << "!" << endl;
    return 0;
}

2. Форматування дробових чисел (iomanip)

За замовчуванням C++ виводить дробові числа без зайвих нулів. Щоб встановити точну кількість знаків після коми, використовують прапорці fixed та setprecision(n) з бібліотеки <iomanip>.

#include <iostream>
#include <iomanip> // Обов'язково для setprecision
using namespace std;

int main() {
    double pi = 3.14159265;

    cout << fixed << setprecision(2);
    cout << "Число Pi з 2 знаками: " << pi << endl; // Виведе 3.14

    return 0;
}

5. Практичні завдання

Завдання 1. Програма вітання.
Користувач вводить ім'я (одне слово) та вік. Програма виводить картку у форматі: "Name: [ім'я], Age: [вік]". 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    int age;

    cout << "Введіть ім'я та вік: ";
    cin >> name >> age;

    cout << "Name: " << name << ", Age: " << age << endl;
    return 0;
}
Завдання 2. Середнє арифметичне 3 чисел.
Зчитати 3 дробових числа (double) і вивести їхнє середнє арифметичне з точністю до 2 знаків після коми.
Розкрити розв'язок 
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double a, b, c;
    cout << "Введіть 3 числа: ";
    cin >> a >> b >> c;

    double avg = (a + b + c) / 3.0;

    cout << fixed << setprecision(2);
    cout << "Середнє арифметичне: " << avg << endl;
    return 0;
}
Завдання 3. Площа прямокутного трикутника.
Користувач вводить довжини двох катетів a та b. Обчислити та вивести площу за формулою: S = (a * b) / 2.
Розкрити розв'язок 
#include <iostream>
using namespace std;

int main() {
    double a, b;
    cout << "Введіть катети a та b: ";
    cin >> a >> b;

    double area = (a * b) / 2.0;

    cout << "Площа трикутника: " << area << endl;
    return 0;
}
Завдання 4. Повне ім'я через getline.
Зчитайте за допомогою getline ПІБ користувача та виведіть привітання.
Розкрити розв'язок 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string fullName;
    cout << "Введіть ПІБ: ";
    getline(cin, fullName);

7. Підсумкове завдання та Чекліст

Підсумкове практичне завдання: «Чек покупки»
Напишіть програму, яка запитує назву товару (з можливими пробілами), ціну за одиницю та кількість. Програма повинна вивести назву товару та загальну вартість із 2 знаками після коми.
Перевірити рішення підсумкового завдання 
#include <iostream>
#include <string>
#include <iomanip>
using namespace std;

int main() {
    string productName;
    double price;
    int count;

    cout << "Введіть назву товару: ";
    getline(cin, productName);

    cout << "Введіть ціну товару: ";
    cin >> price;

    cout << "Введіть кількість: ";
    cin >> count;

    double total = price * count;

    cout << "\n--- ЧЕК ---" << endl;
    cout << "Товар: " << productName << endl;
    cout << fixed << setprecision(2);
    cout << "Разом до сплати: " << total << " грн" << endl;

    return 0;
}
